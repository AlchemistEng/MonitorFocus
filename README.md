A multi-monitor focus and magnification utility for Windows.

## Purpose

MonitorFocus is designed to make content easier to see across multi-monitor Windows systems.

It provides **Full Screen**, **Pointer Lens**, and **Dock Window** magnification modes for accessibility, reading, concentration, demonstrations, and detailed visual work.

## Privacy

MonitorFocus processes pointer and display information locally on this device.

The application does not upload or transmit screen content, pointer coordinates, display information, or application preferences.

Application preferences are stored locally in the application's Windows settings storage.

## Technology

MonitorFocus is built for Windows and uses the **Windows Magnification API** to display magnified desktop content. **Digital Clarity** features help with different visual conditions and disabilities.

Magnification is performed locally by Windows. MonitorFocus does not create permanent screen recordings or screenshots.

## Development Status

MonitorFocus is under active development. Features and interface details may change as accessibility, stability, and multi-monitor support are improved.

The current stable feature set includes:

- Full Screen Magnification
- Pointer Lens Shapes
- Dock Magnification
- Persistent Preferences
- Digital Clarity
- Color Inversion
- Multi-Monitor Support
- Hybrid CPU / GPU Rendering
- Custom Keyboard Shortcuts
- Emergency Stop Shortcut

## Important Notice

MonitorFocus is an accessibility and productivity aid. It is not a substitute for professional medical advice, diagnosis, treatment, or prescribed assistive technology.

> **Emergency stop:** Press **Ctrl + Alt + Shift + M** at any time to immediately stop visual processing, dimming, and magnification.
